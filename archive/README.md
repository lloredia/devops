# Archive

Material kept for history and not part of the learning path. Nothing here was deleted lightly: folders that were personal, employer-specific, unfinished, or unsafe to present as exercises live here instead.

Do not assign this tree as coursework. In particular, do not run anything under `security-scratch/` or `recon-scratch/`, and do not run the stack-overflow experiments under `assembly-experiments/`. Those files are historical notes, not labs.

| Path | What it was |
| --- | --- |
| `personal-devices/` | ASUS USB Wi-Fi driver notes and Razer keyboard lighting scripts |
| `personal-shell/` | Login-banner aliases from a personal host |
| `recon-scratch/` | Old network-recon scripts, renamed so a crude directory name is gone |
| `security-scratch/` | Historical offensive notes (availability script, shellshock, reverse-shell text, privilege notes, an XSS trace). A captured home-directory archive that contained scan tools and a stripped `sshd` binary was removed rather than archived |
| `assembly-experiments/` | NASM experiments that are not the hello-world introduction, including shellcode and stack-overflow samples, plus a scraped syscall-table webpage |
| `wordpress-prod/` | Production-shaped WordPress Compose files and helper scripts. Live database passwords were replaced with `REDACTED_ROTATE_ME`. A backup tarball that held a second set of passwords was removed |
| `ops-notes/` | Unstructured EC2 and DNS scratch notes. A password-like string was redacted |
| `employer-compose/` | Internal AEM / BATO Compose files that are not reusable examples |
| `scratch/` | ASCII art, one-off curl notes, and similar grab-bag files |
| `unrelated/` | Empty Maven POMs and a removed Elasticsearch index archive |
| `dev-ops-placeholders/` | Empty or one-line notes from `lloredia/Dev-Ops` (Azure, MQ, a misc AWS file) |
| `branding/` | Logo, original Dev-Ops README, and the GPL-3.0 text that accompanied that repository |

Compiled objects, audio files, `__pycache__` archives, Wi-Fi handshake captures, and a private key bundle were removed from the tree. They remain in git history until the history is rewritten.
